# Документация Outfitly

Для знакомства с проектом начните с архитектуры. Для конкретной задачи выберите
документ из таблицы ниже.

| Документ | Содержание |
| --- | --- |
| [Архитектура](architecture.md) | Слои, зависимости, доменная модель, хранение и обработка запросов |
| [Разработка и запуск](development.md) | Конфигурация, сборка, миграции и проверки |
| [HTTP API](../src/backend/Outfitly.Api/README.md) | Маршруты, JSON-контракт, ответы и авторизация |
| [Infrastructure](../src/backend/Outfitly.Infrastructure/README.md) | EF Core, ограничения БД и команды миграций |
| [Стратегия тестирования](../tests/backend/Outfitly.Tests/README.md) | Важные сценарии, изоляция и PostgreSQL-тесты |

Для запуска используйте инструкцию разработки. Каждый документ отвечает за свою область:
не копируйте таблицы маршрутов, команды миграций и доменные правила — ставьте ссылки.
Ссылки используют относительные пути без номеров строк.
Отложенные возможности отмечаются отдельно.
