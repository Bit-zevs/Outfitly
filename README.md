# Outfitly

Учебное приложение для личного гардероба: вещи по категориям, их характеристики,
образы, публикация и доступ по ссылке.

**[Открыть демо Outfitly](https://outfitlyapp.ru/)**

## Что можно сделать

1. Добавьте вещь в гардероб. Укажите категорию и характеристики, загрузите фото.
2. Соберите образ из сохранённых вещей.
3. Опубликуйте образ или отправьте ссылку на него.

## Реализация

- API на ASP.NET Core (.NET 10), хранение данных в PostgreSQL через EF Core.
- Интерфейс на HTML, CSS и JavaScript без фреймворка.
- Автотесты бэкенда и фронтенда в GitHub Actions. После успешных проверок основной ветки запускается автоматический деплой.
