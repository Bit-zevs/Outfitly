# Outfitly

Учебное приложение для личного гардероба: вещи по категориям, их характеристики,
образы, публикация и доступ по ссылке.

## Навигация

- [Документация](docs/README.md) — выбор документа по вопросу.
- [Архитектура](docs/architecture.md) — слои, модель данных и границы ответственности.
- [Разработка и запуск](docs/development.md) — требования, конфигурация и проверки.
- [HTTP API](src/backend/Outfitly.Api/README.md) — маршруты и контракты.

Для знакомства с проектом начните с архитектуры. Контракты и инструкции запуска
описаны в соответствующих документах.

## Структура

```text
src/backend/    # Domain, Application, Infrastructure, Api
src/frontend/   # HTML/CSS/JavaScript и скрипты разработки
tests/backend/  # xUnit: домен, use cases, хранение, HTTP
tests/frontend/ # HTTP-проверки dev server
docs/           # Архитектура и навигация
```

Backend использует .NET 10 и EF Core/PostgreSQL. Аутентификация и интеграция frontend
отложены; защищённые маршруты сейчас возвращают 401. Точное текущее состояние
описано в [архитектуре](docs/architecture.md).
